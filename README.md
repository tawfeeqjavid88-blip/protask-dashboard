# ProTask — Productivity Dashboard

A modern, responsive task management dashboard built with vanilla web technologies.

## Features
- **Task Management**: Add, complete, and delete tasks with ease.
- **Priority System**: Categorize tasks by High, Medium, or Low priority.
- **Smart Filtering**: Switch between All, Active, and Completed views.
- **Theme Support**: Integrated Light and Dark mode toggle.
- **Local Persistence**: Stores task state in `localStorage` so data survives page refreshes.

## Tech Stack
- HTML5
- CSS3 (Custom Variables & Responsive Flexbox)
- JavaScript (DOM manipulation & LocalStorage API)
